PROJETO: E.D.E.N. — Ecological Development in Exo-Environments
         (Desenvolvimento Ecológico em Exoambientes)

RESUMO:
  Sistema de Mission Control AI baseado em LLM para monitoramento
  e controle autônomo de uma biocápsula botânica orbital. A IA
  interpreta telemetria simulada de sensores IoT e gera análises
  de status, previsões de falha e recomendações de ação usando
  técnicas avançadas de Prompt Engineering.

MODELO DE IA:
  Llama 3.1 8B Instruct via HuggingFace Inference API

TÉCNICAS DE PROMPT ENGINEERING:
  - System Prompt com persona e regras operacionais
  - Chain-of-Thought (análise de status e previsão de falha)
  - Few-Shot Prompting (recomendações de ação)
  - Function Calling / Structured Output (relatório JSON)

INJEÇÃO DE CONTEXTO:
  Prompt Augmentation direta — dados de telemetria dinâmica
  injetados no prompt no momento da inferência (sem RAG)

PLATAFORMA: Kaggle
